# OpenVPN Management Suite for Paymenter

### **The ultimate commercial-grade solution for automated VPN provisioning and real-time management.**

This high-performance OpenVPN Management Suite for Paymenter offers a complete, commercial-grade solution for automated VPN provisioning and real-time resource management. The system is powered by a hardened one-click auto-installer that deploys a secured OpenVPN server, a private Certificate Authority, and a companion Python-based Manager API to track persistent usage metrics. Once linked to Paymenter, the extension handles the entire lifecycle of a service—from generating unique, multi-device `.ovpn` profiles and certificates upon payment to enforcing sophisticated aggregate data caps and dynamic bandwidth throttling based on the user's plan. End-users are greeted by a premium, modern dashboard featuring live interactive traffic graphs and real-time connection status, providing a professional self-service experience that rivals major commercial VPN providers while remaining entirely self-hosted and automated.

---

## Key Features

*   **One-Click Deployment**: Hardened auto-installer handles CA setup, firewall rules, NAT routing, and API deployment in minutes.
*   **Real-Time Live Dashboard**: Stunning client UI with live Download/Upload graphs and connection health tracking.
*   **Smart Data Caps**: Set monthly aggregate data limits (e.g., 5GB/month) across all of a user's devices with automated suspension.
*   **Dynamic Throttling**: Limit client speeds (Mbps) based on their specific Paymenter service plan.
*   **Multi-Device Support**: Create multiple secure profiles per service, each with its own ready-to-import `.ovpn` bundle.
*   **Hardened Security**: AES-256-GCM encryption, TLS-Crypt obfuscation, and automated Let's Encrypt SSL for the API.
*   **Cross-Platform Ready**: Seamlessly compatible with OpenVPN Connect (iOS/Android), Tunnelblick (macOS), and Windows.

## Installation

### **1. Server Deployment**
Run the interactive deployment script on your VPS as **root**:

```bash
bash -c "$(curl -sSL https://raw.githubusercontent.com/Pweppapig0/OpenVPN/main/openvpn_auto_install.sh)"
```

**What the script does:**
1. Installs OpenVPN & Easy-RSA (Certificate Authority).
2. Deploys the Python Manager API & SQLite database.
3. Configures UFW/IPTables for internet routing.
4. Generates an SSL certificate via Let's Encrypt.
5. **Outputs your Base URL and API Token.**

### **2. Paymenter Integration**
1. Zip up the `OpenVPN` extension folder from your purchase.
2. In Paymenter, go to **Admin > Extensions > Installable** and upload the ZIP.
3. Open the **OpenVPN** extension settings and paste your:
   - **Base URL**: e.g., `https://vpn.example.com`
   - **API Token**: The secure token generated by the installer.

---

## How it Works
On service creation, the Paymenter extension communicates with the companion Manager API on your VPN host. The API uses Easy-RSA to generate unique client certificates, builds an `.ovpn` configuration, and sets up correct routing via the Client Configuration Directory (CCD). The API polls the OpenVPN Management socket natively to track live traffic and reports it back to Paymenter for automated enforcement of your data caps and bandwidth limits.
